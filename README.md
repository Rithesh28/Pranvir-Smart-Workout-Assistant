# 📖 Overview

PRANVIR is an intelligent workout assistant that helps users perform exercises with correct posture using Artificial Intelligence and Computer Vision.

The application detects body landmarks in real time, recognizes supported exercises, counts repetitions automatically, and provides posture correction feedback to reduce the risk of injuries and improve workout quality.

This project combines a modern React frontend with a Flask backend and integrates MediaPipe and TensorFlow models for real-time exercise analysis.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Rithesh28/Pranvir-Smart-Workout-Assistant.git
```

```bash
cd Pranvir-Smart-Workout-Assistant
```

---

## Backend

```bash
cd pranvir-workout-assistant1/backend

pip install -r requirements.txt

python app.py
```

---

## Frontend

```bash
npm install

npm run dev
```
