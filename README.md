# 🏋️‍♂️ Pranvir - Smart Workout Assistant

A smart AI-powered workout assistant that analyzes exercise form using CNN models and MediaPipe pose detection.

## ✨ Features

- **AI-Powered Analysis**: Uses trained CNN models for squat and lunge detection
- **Real-time Feedback**: Provides instant form corrections
- **Image Upload**: Analyze exercise form from uploaded images
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Modern UI**: Dark theme with smooth animations

## 🛠️ Tech Stack

### Frontend
- HTML5, CSS3, JavaScript (ES6+)
- Responsive design with CSS Grid & Flexbox
- Font Awesome icons

### Backend
- Flask (Python web framework)
- OpenCV for image processing
- MediaPipe for pose detection
- TensorFlow/Keras for CNN models

### AI/ML
- Custom CNN models for exercise classification
- MediaPipe for real-time pose estimation
- OpenCV for computer vision tasks
